# Обводилка

Веб-приложение для рисования по камере: телефон на штативе над листом, на экране — живое изображение с камеры и полупрозрачная картинка поверх. Обводите линии карандашом на реальном листе.

**Открыть:** https://xaleksx17-boop.github.io/trace-draw/

## Что умеет (MVP)

- Картинка: снять камерой, выбрать из галереи, вставить из буфера; последняя запоминается
- Наложение на камеру с регулировкой прозрачности
- 1 палец — сдвиг, 2 пальца — масштаб и поворот; 🎯 — вернуть по центру
- 🔒 Замок — фиксирует картинку, чтобы случайно не сдвинуть
- 👁️ Показать/скрыть картинку, 🔦 фонарик, ⬇️ свернуть панель
- Зум камеры (аппаратный, если браузер поддерживает, иначе программный)
- Настройки ⚙️: фильтры (оригинал / ч/б / контур / инверсия), яркость, контраст, порог и толщина контура, цвет линий, зум по умолчанию, зеркальное отражение
- Экран не гаснет, полноэкранный режим, работает офлайн, можно «Установить» на рабочий стол

Всё работает в браузере, картинки никуда не отправляются. Лучше всего — Chrome на Android.

## Файлы

`index.html` — разметка, `style.css` — оформление, `app.js` — логика, `sw.js` — офлайн-кэш (при изменениях поднять версию `CACHE`), `manifest.json` — установка как приложение.
