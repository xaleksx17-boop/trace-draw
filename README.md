# Обводилка

Веб-приложение для рисования по камере: телефон на штативе над листом, на экране — живое изображение с камеры и полупрозрачная картинка поверх. Обводите линии карандашом на реальном листе.

**Открыть:** https://xaleksx17-boop.github.io/trace-draw/

## Что умеет

- Картинка: снять камерой, выбрать из галереи, вставить из буфера
- Обрезка, поворот на 90°, отражение перед рисованием
- «Мои рисунки» — список проектов: у каждого запоминаются обрезка, положение, размер, прозрачность, фильтры и сетка
- #️⃣ Сетка поверх картинки (число клеток и цвет — в настройках)
- Наложение на камеру с регулировкой прозрачности
- 1 палец — сдвиг, 2 пальца — масштаб и поворот; 🎯 — вернуть по центру
- 🔒 Замок — фиксирует картинку, чтобы случайно не сдвинуть
- 👁️ Показать/скрыть картинку, 🔦 фонарик, ⬇️ свернуть панель
- Зум камеры (аппаратный, если браузер поддерживает, иначе программный)
- Настройки ⚙️: фильтры (оригинал / ч/б / контур / инверсия), яркость, контраст, порог и толщина контура, цвет линий, зум по умолчанию, зеркальное отражение
- 💡 Световой стол: без камеры, лист кладётся прямо на экран; 🔒 блокирует весь экран, разблокировка — удержание левого верхнего угла 2 с
- ⏺️ Запись видео процесса: обычная (×1) или ускоренная (×5, ×10, ×30), с картинкой или без; 📸 фото готового рисунка — всё сохраняется в «Загрузки»
- Мигание картинки: периодически скрывается, чтобы видеть свой рисунок
- «Поделиться» картинкой из других приложений (после установки на рабочий стол)
- Экран не гаснет, полноэкранный режим, работает офлайн, можно «Установить» на рабочий стол

Всё работает в браузере, картинки никуда не отправляются. Лучше всего — Chrome на Android.

## Файлы

`index.html` — разметка, `style.css` — оформление, `app.js` — логика, `sw.js` — офлайн-кэш (при изменениях поднять версию `CACHE`), `manifest.json` — установка как приложение, `lib/mp4-muxer.js` — сборка MP4 для таймлапса ([mp4-muxer](https://github.com/Vanilagy/mp4-muxer), MIT).
